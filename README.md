# Novatrix Azure-Uppgift-6B

Uppgiften ligger separat i `6B/` och omfattar alla tre modulerna: Azure Function med journal, könotis och mejl; webb som scale set med lastbalanserare och autoskalning; samt Azure Monitor, Log Analytics och Azure Policy.

Se [modulens översikt](6B/README.md) för krav, körning och begränsningar. Rapport och bildbevis hålls separat från GitHub.
